01 / Concept

头脑风暴 & 元素联想 Element Mapping

这款游戏的设计内核，是一套 "现实文具 → 游戏机制" 的系统化映射。每一件文具的真实特性，都被转译成一条自洽的玩法规则。

现实元素游戏内转化关联逻辑
订书机BOSS 发射订书钉弹幕"穿刺" 特性 → 弹幕攻击
橡皮擦擦除敌人护盾 / 地形障碍"修正" 功能 → 清除类技能
胶带黏住敌人 3 秒黏性 → 控制类效果
铅笔屑可收集货币，升级合成台现实垃圾 → 资源化
台灯光晕仅在光晕内恢复生命灯光象征庇护 → 限定恢复区
作业本折痕迷宫地形生成纸张折叠几何 → 程序化关卡
午后蝉鸣倒计时阶段背景音夏日紧迫感 → 强化时间焦虑
儿童涂鸦技能图标 / UI 风格稚拙笔触 → 美术统一性

03 / Crafting

合成系统 Crafting System

作业本展开式合成界面。文具两两组合，衍生出攻击、防御、控制三系道具，并保留随机合成的探索惊喜。

类型配方产物 / 效果
基础铅笔 + 胶带胶带铅笔鞭：攻击距离变长 + 黏性短暂黏敌
基础橡皮 + 回形针回形针橡皮盾：抵挡数次攻击
进阶飞页书签 + 隐形便签幻影飞书：操控幻影书撞击 + 眩晕
随机任意两件随意组合概率触发未知新道具，战斗中探索
04 / Enemies

敌人 & Boss 设计 Learning Stress, Materialized

敌人设计是 "学习压力的具象化"。每个敌人都从一件文具的特性长出独有的攻击模式与破解方式。

订书机 BOSS · 精灵图循环动画
  • 订书机（核心 BOSS）：金属外壳，远程弹射订书钉，近战夹伤；需用回形针干扰其装订机制找破绽。
  • 错题集幽灵：揉皱纸张 + 红墨水弹；被 "胶带铅笔鞭" 黏住即无法攻击。
  • 直尺骑士：手持直尺高速冲刺；"回形针橡皮盾" 可弹飞使其陷入混乱。
  • 数学公式蛇：数字符号组成，需橡皮擦除核心 "等号" 击败。
  • 迟到时钟 BOSS：长腿摆钟，投掷分针似追踪导弹；利用书堆 / 笔筒躲避。

— / Target Users

目标用户 & 验证计划 Design Hypotheses

  • 目标群体：17–30 岁怀旧玩家，渴望用简单文具重拾童年想象力，并在轻松策略中获得成就感。
  • 验证设计：BOSS 战前用 "脚步声逼近" 音效配合 3 分钟时间压力，测试玩家对压力机制的接受度。
  • 计划中的数据可视化：合成组合需求扇形图 / 场景探索热力图 / 反馈词云（"童年回忆""策略深度""轻松上手"）。
// 说明：本段为设计阶段的用户假设与验证计划，非已完成的真实用户测试结论。
