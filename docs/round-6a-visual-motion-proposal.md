## 0. Round 6C 用户修订（当前有效）

用户在 Round 6C 验收时明确要求不再保留双表面方案，而是“按照 GAME WORK 的部分改动效和配色”，随后确认“先按这样全量修改”。因此本文件中 V-03 的浅灰 / 橙色保留方案从此被以下决定覆盖：

- 首页八个区块、全站导航和 Archive 全部迁移到 Void Black / Surface Black / Signal White / Signal Gray / Acid Lime。
- 中文正文、履历、项目事实、真实媒体、入口与区块顺序不变。
- GAME WORK 继续是唯一高强度 560ms 像素媒体转场。
- 其他区块只扩展 120–180ms 的当前区块状态段、按钮反馈和 Archive 预览替换。
- 删除旧橙色鼠标追踪点阵，背景改为无监听器、无逐帧更新的静态 12px / 48px Signal 网格。
- 所有动效在 Reduced motion 下为 0ms 稳定状态。

以下第 1–8 节保留为 Round 6A / 6B 的历史决策记录；发生冲突时以本节和两份 v3 / v4 规范为准。

## 1. 结论

Round 6A 推荐把已经通过验收的 Pixel Signal 从“GAME WORK 的完整舞台”扩展为全站的“像素控制层”，而不是把八个区块全部改成黑色 CRT 界面。

具体含义：

- GAME WORK 继续是唯一完整的黑色运行窗口，也是唯一使用强度 3 / 5、560ms 像素拆散与聚合的区块。
- 其他区块保持当前浅灰编辑式排版和真实内容结构，只把导航、英文短标题、区块编号、状态词、标签与按钮纳入同一套像素字体、12px 网格和硬边规则。
- 中文正文、履历长文、项目事实、真实媒体和 Archive 大量项目说明继续使用当前易读字体与结构。
- Round 6 只新增一个低强度动效：导航的当前区块状态。其他动作是删除旧干扰或收敛已有交互，不复制 GAME WORK 转场。

这套方案的目标是让访问者在首屏就感到“这是一个有像素系统意识的游戏开发作品集”，同时仍能像招聘网站一样快速读懂职业定位和项目证据。

## 3. 推荐视觉方案：Pixel Control Layer / 像素控制层

### V-01 字体职责

- Fusion Pixel 用于：Hero 英文职业标题、各区块英文主标题、导航、区块编号、英文 eyebrow、状态词、技术标签、按钮短文案。
- 当前正文系统用于：中文段落、履历、职责说明、项目长摘要、奖项与联系信息。
- 中英混排项目标题只在短标题中使用 Fusion Pixel；标题过长时优先降低一个离散字号，不压缩字宽。
- 字号优先落在 12 / 24 / 36 / 48 / 72 / 96px 级别，手机端英文标题降级到 36 / 48px。

### V-02 12px 控制网格

- 区块编号统一为像素字体，旁边增加一段静态 12px 棋盘校准标记。
- 导航当前项、标签、按钮、状态段的内边距优先使用 6 / 12 / 24px。
- 所有控件保持完整矩形与 1px 硬边，不恢复已删除的黑色缺口，不使用胶囊按钮。
- 棋盘格只出现在编号或状态位置，不铺满背景。

### V-03 双表面配色

推荐保留当前已经成立的双表面，而不把全站改成黑色：

- 浅色编辑表面：Hero、Systems、Experience、Relevant Work、Archive、Profile、Contact 继续使用当前浅灰、深色文字和橙色强调。
- 黑色运行表面：GAME WORK 继续使用 Void Black、Signal White、Acid Lime、Moss Shadow。
- Acid Lime 不直接作为浅灰底上的小号正文颜色；全站导航的当前项使用深色矩形承载 Acid Lime，保证对比度。
- 橙色仍属于浅色内容层的重点和链接，不与 GAME WORK 的“当前运行状态”争夺职责。

### V-04 明确不加入

- 不增加右侧常驻像素主体、像素月球、人物或抽象球体。
- 不做全站黑底、全页 CRT 扫描线、持续故障、色散、闪烁或窗口堆叠。
- 不给每个 Archive 项目添加独立像素动画。
- 不改变任何项目名称、项目事实、媒体、入口、顺序或折叠内容。

## 5. N-01 导航状态的精确行为

### 桌面

- 使用离散区块状态，不做跟随滚动的进度条，也不连续计算像素宽度。
- 当前项从普通灰字切为深色矩形，内部使用 Acid Lime 文字或 6px 状态块。
- 切换时间 120–150ms，使用 `steps(1, start)`；它应当像系统状态翻转，而不是柔和淡入。
- 每次只有一个导航项具有 `aria-current="location"`。
- Hero 位于首屏时，品牌 `ZHU YIJIA` 承担当前状态；进入 GAME WORK 后再激活普通导航项。

### 手机

- 菜单关闭时，按钮显示 `02 / MENU` 这类当前编号，不播放像素动画。
- 菜单打开时，当前项使用与桌面相同的深色矩形和 Acid Lime 状态块。
- 不锁滚、不加入抽屉滑动或全屏转场。

### 实现边界

- 状态检测使用 `IntersectionObserver` 或离散 ScrollTrigger，不能在滚动每帧写 React state。
- 只改变 class、`aria-current`、颜色与静态状态块；不动画 width、height、top、left 或阴影。
- 监听器与观察器在组件卸载时清理。
