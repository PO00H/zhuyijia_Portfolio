# Archive 项目名称更新草案

> 版本：v4 · 2026-08-11  
> 状态：最终名称已确认并同步到网站项目数据。  
> 调研范围：逐项查看 10 个 Web Design 独立页面、NewFace 页面，以及保留的 5 个 3D / Visual 项目的现有预览与项目描述。  
> 主要受众：中国招聘方；项目名称采用中文为主、必要英文品牌名为辅。

## 1. 命名规则

建议统一采用：

```text
英文品牌或作品名 — 中文内容说明
```

Web Design 单独采用：

```text
网站应用方向 — 中文内容说明
```

- 3D 与 AI 项目可以保留有识别度的英文作品名；Web 项目主标题优先写应用方向，原品牌名留在页面内容或中文说明中。
- 中文部分直接说明作品是什么，避免只写 `Frontend`、`Join Now`、`I / II`。
- 临摹或重制类网页明确使用“界面习作”“网站复现”等中文表述，避免被理解为原品牌正式项目。
- 同一品牌的两个版本用不同的交互特征区分，不再使用 `Typeface I / II`。
- 技术缩写如 `UE5`、`PBR`、`AI` 可以保留，其他能力描述优先使用中文。
- Web 项目的品牌名不再占据主标题；招聘方先看到“音频工具网站、企业服务网站、AI 创作平台”等应用方向。
- “你的最终名称”一栏是网站当前采用的名称；“原名称”仅作为改名前记录保留。

### Web 页面判断依据

#### `frontend-001`

页面实际是一个专业音频工作站概念，包含模块连接、DSP 信号链、64 通道路由、频谱分析和主控系统。因此 Archive 名称先写“音频工具网站”，`SYNTHWAVE OS` 继续保留在页面品牌中。

#### `frontend-002`

页面不只是等待名单：它同时包含创意平台预热、早期加入队列和 15 位候选人投票。因此主标题直接归类为“创意平台网站”，再说明等候名单与候选人投票两项功能。

#### `frontend-003`

页面品牌实际显示为 `SYNTH.OS`，视觉是孟菲斯风格的高密度控制台，而不是普通数据看板。

#### `frontend-004`

页面内容围绕建筑法规、合规审查、快速申报和从咨询到审批的完整服务流程。“建筑合规导航平台”比公司名本身更能说明页面主题。

#### `frontend-005`

这是带字重、字形、语言与字体测试器的 EXAT 字体展示网站，并明显以 Hot Type 网站为研究对象。名称应诚实标明“界面习作”或“网站复现”。

#### `frontend-006`

同样围绕 EXAT，但重点是动态字形、拖拽控制、鼠标变形与涟漪交互。因此归类为“互动字体网站”，再用 `EXAT 动态排版实验` 与上一项静态字体展示站区分。

#### `frontend-007`

当前 Archive 名称与实际页面完全不符。页面已经是 `NEXUS OS v2.0`，内容为结合量子同步、神经交互、无限画布和 AI 助手的终端式创作平台，因此改为 `AI 创作平台 — 终端式智能创作系统`。

#### `frontend-008`

页面是黑白高对比的创意前端开发者作品集，核心是 React、Three.js、交互技术和工程宣言。因此归类为“开发者作品集”，再说明它展示创意前端与交互项目。

#### `frontend-009`

页面是实时系统性能与基础设施监控面板，包含吞吐量、延迟、错误率、数据管线、Kubernetes 和多云状态。“实时系统数据看板”比“数据可视化”更具体。

#### `frontend-010`

页面是一个同时展示前端、C++、UE5、Blender 与 3D Art 的个人作品集概念。因此归类为“个人作品集”，并用“前端与 3D 综合展示”说明核心定位。
