# 作品集视觉方向：ASCII + Dithering Background Field

> 版本：Visual Direction v4
> 日期：2026-08-13
> 状态：方案 A 已接入正式首页与 Archive，等待配色与材质验收；布局与项目媒体保持不变
> 配套动效：[`portfolio-motion-design.md`](portfolio-motion-design.md)

## 1. 已确认的基础

现有网站的信息架构、版式、项目顺序、中文内容和真实项目媒体已经满意，均不在本轮重新设计范围内。视觉更新只处理背景层、配色和少数明确的动效事件。

真实项目封面、截图、视频和 Sketchfab 内容保持原样；它们不进入 ASCII、Dithering、点阵或鱼眼渲染管线。

## 2. 视觉母语言

全站背景使用 **ASCII + Dithering 动态质感**：以规则的小型字符、短矩形或点阵单元构成低分辨率明暗，并用阈值变化形成颜色与留白的交界。

它不是终端界面、像素游戏 HUD、抽象线路图，也不是随机流体色块。背景应像一个持续运行的弧形矩阵场：单元有秩序、运动有方向、颜色是信息的一部分。

### 常驻背景层

- 覆盖整个页面背景，可超出视口边缘；不采用 ArcMatrix 的胶囊外轮廓。
- 单元使用细小、规则、密集的 Dither 字符/短格/点，不使用杂乱字符坡度或假终端文案。
- 网格通过弧形坐标变形获得曲面感：边缘压缩、中心较松，行列具有轻微弧度。
- 背景只在自身画布内产生轻微鱼眼；所有 DOM 文字、按钮、媒体和点击坐标保持正常。
- 背景永远 `pointer-events: none`，不拦截鼠标、键盘、滚动或媒体控制。

### 特殊点阵事件层

- 采用点阵海报参考中的大小圆点、疏密、缺口和局部抽象形体。
- 只用于点击、项目切换或明确的章节激活等低频事件。
- 事件结束后回落并融入底层 Dither，不常驻，不覆盖项目媒体或长正文。

## 3. 色彩是结构信息

第一轮背景直接验证红、青、白三者的关系，不先做灰度替代。

| Token | 参考角色 | 职责 |
|---|---|---|
| Field White | 高亮留白 | 页面基底、阈值交接和呼吸缓冲区 |
| Coral Field | 珊瑚红场 | 暖相位、前景密度与局部事件起始 |
| Cyan Field | 青绿色场 | 冷相位、反向密度与空间深度 |
| Deep Cyan / Signal Red | 深青 / 信号红 | 只用于局部重叠、文字附近或极短点击锚点 |

颜色不是两张模糊渐变图的透明度互换。每个单元由色场权重和阈值共同决定为红、青或留白；白色交接带必须保留，不能被柔焦混色替代。

方案 A 的正式网站色板冻结为一套可继续微调的“复古未来像素清新”基础：页面底色 `#f3f5f3`、主要文字 `#172125`、主青 `#28b6c3`、深青 `#2d929b`、交互青 `#169eae`、Dither 留白 `#e0e0e0`。旧有黑 / 深绿 / 酸性黄绿语义退出正式页面；深色只保留在真实项目媒体自身及其必要的媒体承载框内。

## 4. 与参考的职责对应

| 参考 | 采用 | 不采用 |
|---|---|---|
| 点阵海报 | 规则圆点、点径差异、疏密、断裂、远看读形体近看读单元 | 海报版式、人物形体、标题与测量框的直接复制 |
| ArcMatrix 动画 | 弧形矩阵、Dither 阈值、红青白交接、稳定呼吸 | 胶囊外轮廓、品牌文字、把它当成独立漂浮物 |

## 5. 明确不做

- 不重做现有网站布局或每次探索都制作一比一网站。
- 不使用黑底终端、假窗口、假 FPS、假命令行、C++ 雕塑或线路图。
- 不使用暖琥珀 / 紫色功率蔓延、酸性黄绿 Pixel Signal 或四色随机流体作为当前方向。
- 不把方向性背景波解释为加载、页面 wipe 或 CTA 完成状态。
- 不使用持续鼠标吸引、排斥、拖尾或高频粒子。
- 不把大圆点事件层覆盖在项目封面、视频或正文上。
- 不为制造“呼吸”缩放整个网页、DOM 或项目媒体。

## 6. 实现边界

- 背景以一个 Canvas 或等效批量渲染层实现；不为每个单元创建 DOM 节点。
- 稳定态保持低频，离屏和页面隐藏时暂停；Reduced Motion 显示静态中间相位。
- 轻鱼眼只扭曲背景采样坐标，强度以不影响正文附近可读性为准。
- 背景层不读取或采样真实作品媒体。

## 7. 下一步验收

Motion Study 01–06 已通过；用户选择方案 A：正式网站改为浅色基础表面，并沿用普通无环面、右上→左下、105% 密度、8% 内突与青灰色板。当前接入只启用自主呼吸背景，不把实验页的点击事件带入网站。下一步只验收首页、项目区与 Archive 的整体色彩、可读性和 Dither 材质强度；验收前不增加新动效。

## 8. 字体与浮动预览收尾

- 正式首页、Archive、导航、按钮、说明文字和浮动预览统一使用 Fusion Pixel 像素字体族，建立复古未来像素语气；真实项目图片、视频与截图不进入字体或点阵处理。
- 左侧品牌与右侧导航标签共用同一视觉中线；手机端品牌与 MENU 同步对齐。
- 03 / 05 浮动预览采用浅底、深墨边框、青色硬阴影与一次性像素网格展开。它是内容辅助层，不改变已确认的栏目布局，也不覆盖真实媒体本身。
