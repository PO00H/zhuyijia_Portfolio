# 朱翊嘉 UE / C++ 作品集设计规范

> 版本：Design System v1
> 日期：2026-08-13
> 状态：当前唯一有效的视觉、动效与页面维护规范
> 实现分支：`codex/redesign/interactive-portfolio`

## 1. 产品目标与执行边界

网站的首要任务是让招聘方快速确认：朱翊嘉是一名以 Unreal Engine 与 C++ 为核心，同时理解玩法、美术资产和生产工具管线的游戏开发者。

已经确认满意并保持不变：

- 首页信息架构、栏目顺序、项目层级和中文内容。
- 真实项目封面、视频、截图、Sketchfab 与独立 HTML。
- GAME WORK 的项目数据结构和 560ms 媒体交接。
- Archive 的分类与项目入口。

当前只允许继续微调配色、Dither 材质强度、已存在的交互节奏和响应式细节。不重新设计整站，不进入旧计划中的 Round 9B–9E。

探索新视觉时只制作独立 Motion Study，不再为每个方向搭建一比一网站。

## 2. 当前页面结构

```text
固定导航
├── 01 Hero / 职业定位
├── 02 Game Work / 核心游戏开发
├── 03 Unreal Systems / UE 技术实验
├── 04 Experience / 实习与生产实践
├── 05 Relevant Work / 视觉与资产管线
├── 06 Archive / 完整作品档案
├── 07 Profile / 履历摘要
└── 08 Contact / 联系与求职行动
```

结构职责：

- Hero 只负责姓名、岗位、能力概述、核心项目与简历入口。
- Game Work 是首页主舞台：真实 UE 项目预留位、ECHOFLASH、Eraser's Odyssey。
- 03 / 05 使用紧凑项目索引；悬浮只帮助辨认，点击在词条下展开内容。
- Experience 以 Meshy.ai 工具与管线经历为主，无端科技为紧凑辅助经历。
- Archive 保存完整作品记录，不与首页核心项目争夺权重。
- 项目事实、名称、年份、标签、媒体和入口只以 `src/data/portfolioProjects.ts` 为准。

## 3. 视觉母语言

正式方向是 **ASCII + Dithering 动态质感**，不是终端网站。

背景由规则、密集、低分辨率的点或短格构成。远看读取色场和空间形体，近看读取离散单元。Dither 阈值决定单元显示主青、深青或底色；颜色变化与填充率同时发生，不使用大面积 CSS 模糊渐变伪造过渡。

明确不采用：

- 黑底终端、假窗口、假 FPS、假命令行和抽象线路图。
- C++ 雕塑、章节字符填充、CTA 向右加载扩散或紫色功率蔓延。
- 随机四色流体、酸性黄绿 Pixel Signal、扫描线故障和高频粒子。
- 持续鼠标吸引、排斥、拖尾或把背景解释为加载进度。
- 对真实项目媒体进行 ASCII、Dither、像素化或鱼眼处理。

## 4. 当前冻结的视觉参数

| 项目 | 当前值 |
|---|---|
| 页面底色 | `#f3f5f3` |
| 主要文字 | `#172125` |
| 主青 | `#28b6c3` |
| 深青 | `#2d929b` |
| 交互青 | `#169eae` |
| Dither 底色 | `#e0e0e0` |
| 几何 | `flat`，普通无环面 |
| 方向 | 右上 → 左下 |
| 点阵密度 | 105% |
| 背景内突 | 8%，只扭曲 Canvas 采样坐标 |
| Canvas 可见度 | 桌面、手机与 Reduced Motion 均为 80% |

“内突”表示背景中心朝观看者鼓起、边缘向中心收拢；不是内凹。Dither 单元发生局部缩放时以自身中心为固定中心，最大尺寸不越过所属网格框。

## 5. 字体

正式首页、Archive、导航、按钮、说明文字和浮动预览统一使用 `Fusion Pixel 12` 简体中文像素字体。

- 字体文件：`public/fonts/fusion-pixel/fusion-pixel-12px-proportional-zh_hans.otf.woff2`（约 648KB，全站唯一字体资源）。
- `index.html` 对该字体使用 `preload`；不导入任何外部字体服务（Inter / JetBrains Mono 的 Google Fonts 导入已移除，仅保留回退声明）。
- 像素字体只使用 400 常规字重；标题与 `strong` 一律不加粗，加粗会产生难看的合成锯齿。
- 页面最终字体锁定必须覆盖遗留的 Inter、JetBrains Mono 和系统中文回退规则。
- 真实项目图片、视频、截图、Sketchfab 和 `public/embed` 内独立作品保持自身字体。
- 中文正文必须在桌面和手机检查换行、行高与可读性，不能只检查标题。

## 6. 常驻背景呼吸

首页与 Archive 共用 `PortfolioDitherBackground`。它是固定、不可点击的 Canvas 气氛层，DOM 内容始终位于其上方。

- 稳定态：桌面 12 FPS，手机 10 FPS。
- 页面隐藏、窗口失焦或组件卸载时停止绘制。
- Reduced Motion 使用静态中间相位。
- 背景不改变布局、滚动、焦点、按钮命中区或项目媒体。
- 当前方向沿右上 → 左下缓慢迁移；没有首尾停顿，也不表达任务完成。

## 7. 同源点击波

正式页面点击会在实际指针位置触发一次约 1800ms 的同源径向波：

- 连续改变现有 Dither 单元的覆盖率、尺寸和主青 / 深青权重。
- 波前使用平滑权重和长尾回落，不叠加 CSS 模糊圆环或额外 DOM 图层。
- 事件期间桌面临时提高到 24 FPS，手机提高到 18 FPS，结束后恢复稳定帧率。
- Canvas 始终 `pointer-events: none`，通过被动窗口监听获取点击，不阻挡页面交互。
- Reduced Motion 不播放点击波。

## 8. 03 / 05 项目索引预览

- 细指针进入词条后显示圆形进度指针；连续停留 1000ms，圆环正好完成并出现预览。
- 提前离开或切换词条会取消本次意图。
- 预览跟随鼠标并优先位于指针右侧 32px，位置限制在视口内。
- 预览通过 Portal 脱离章节层叠上下文，页面层级为 `2147483000`；圆环位于其上一层。
- 打开使用 280ms、6 阶像素块裁切，并叠加一次 8px Dither 网格退场。
- 动效只作用于预览容器，真实视频帧不被点阵化。
- 触屏和粗指针不显示悬浮预览；键盘聚焦直接显示静态预览；Reduced Motion 取消分阶打开。

## 9. GAME WORK 媒体交接

GAME WORK 保留已经验收的共享媒体窗口和 560ms Dither 交接。它只在现有真实媒体之间切换；Upcoming UE 项目没有真实素材时继续使用明确预留状态，不伪造封面、演示或成果。

背景点击波、项目索引预览和 GAME WORK 媒体交接是三套不同职责：

| 系统 | 作用 | 不承担 |
|---|---|---|
| 背景呼吸 / 点击波 | 全站气氛与低频点击反馈 | 项目加载或章节状态 |
| 03 / 05 浮动预览 | 快速辨认项目 | 项目正式展示与媒体改写 |
| GAME WORK 560ms 交接 | 核心项目媒体切换 | 全页背景叙事 |

## 10. 导航与响应式

- 导航固定在视口顶部，页面保留对应起始空间。
- 桌面品牌标识与右侧导航标签共用视觉中线。
- 手机品牌与 MENU 共用视觉中线；菜单必须可操作，不能只显示当前栏目名称。
- 手机降低背景网格与帧率；真实项目媒体保持正常比例。
- 所有关键页面必须验证无水平溢出、键盘焦点可见和 Reduced Motion 降级。

## 11. 开发实验页

- `/ascii-lab`：当前 Dither 参数与点击事件研究页；只在开发环境开放。
- `/asset-lab`：真实素材裁切与派生映射工具；只在开发环境开放。
- `/pixel-lab`：旧媒体交接研究页；不是当前全站视觉规范。

实验页用于验证单变量，不代表要复制一套新网站。正式参数以本文件和 `PortfolioDitherBackground.tsx` 为准。

## 12. 维护与验收

改动设计前先检查本文件，改动项目内容时再读取 [`adding-real-ue-project.md`](adding-real-ue-project.md)。历史提交与 `CODEX_TODO.md` 中的旧方向只用于追溯，不得覆盖本规范。

每次提交前至少完成：

1. 桌面首页、03 / 05 预览、Archive 检查。
2. 390px 手机首页与菜单检查。
3. 中文像素字体与真实媒体不受处理的检查。
4. 键盘、触屏和 Reduced Motion 路径检查。
5. `git diff --check` 与 `npm run build`。

下一阶段必须由用户明确指定；默认只允许修复和微调当前系统，不自行扩展新章节动效或恢复任何已否决方向。
