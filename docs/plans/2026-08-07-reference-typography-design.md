# 参考网站与中文排版设计记录

## 目的

这份记录把参考网站的视觉印象改写为可执行规则。新版不直接复制他人的品牌、素材或 WebGL 技术，而是复用其信息组织、版式节奏和交互连续性，再用朱翊嘉的中文内容与游戏画面重新表达。

## 重新核验后的参考关系

### Dennis Snellenberg：页面骨架

Dennis Snellenberg 的特点不是“极简＋大字”这么简单。页面用少量内容形成多种构图：文字有时占据整屏，有时贴边，有时与媒体交叠；大面积留白和少量圆形操作节点形成张力。项目不是重复的卡片，而是尺寸、位置和进入方向不断变化的连续章节。滚动、悬停和页面切换使用同一种缓动语言，因此用户不会感到每个模块各自动画。

在本网站中复用：大字号中文身份、非对称十二列网格、项目章节的构图变化、圆形或磁性操作反馈、连续页面转场。

不复用：个人品牌文案、浅色配色、客户项目形式和具体视觉资产。

### Aristide Benoist：信息秩序

Aristide Benoist 的项目索引通过编号、完成时间、类型、职责和客户等固定字段建立秩序。文字不是图片说明，而是可浏览的界面；悬停预览负责补充视觉，索引本身仍然成立。

在本网站中复用：项目编号、年份、类别、个人职责的稳定位置，以及文字与封面联动。首页只使用两个大型项目，不复制三十项长索引；完整索引留给 All Works。

### Lusion：滚动节奏

Lusion 把滚动组织成连续提示：首屏告诉用户继续探索，章节之间通过媒体、标题和方向变化承接，页面不会在每次滚动后重新开始一段孤立动画。

在本网站中复用：滚动提示、项目媒体的遮罩揭示、轻微速度差和页面切换的连续感。

不复用：全屏 Canvas、持续 WebGL、复杂三维背景和高成本图片序列。

## 当前新版的问题

1. 首页由相同的“双栏图片＋文字”重复两次，只有左右换位，没有真正的构图变化。
2. 动效只有整体淡入和图片悬停缩放，滚动、光标、链接和路由切换没有共同节奏。
3. 新版外壳没有接回旧版已有的平滑滚动和自定义光标。
4. 中文标题沿用了英文展示字体的极端负字距；`朱翊嘉` 使用 `-0.09em`，汉字结构被过度压缩。
5. 中文、英文、数字和微型标签共用同一套字号与字距规则，中文标签因此过小、过疏。
6. 正文没有统一行长、CJK 断行、标点挤压或中西文自动间距规则。

## GitHub 中文排版研究

### 采用的依据

- [sofish/typo.css](https://github.com/sofish/typo.css)：中文优先字体栈、正文 `1.75` 行高、严格 CJK 换行、正文最大 `48em`、中西文自动间距和标点处理。
- [sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines)：中文与英文、中文与数字之间留空格；全角标点两侧不额外加空格；专有名词保持正确大小写。
- [ethantw/Han](https://github.com/ethantw/Han)：把汉字排版视为语义、字体和高级排版共同组成的系统，而不是零散字号微调。
- [vinta/pangu.js](https://github.com/vinta/pangu.js)：中西文自动空格可通过脚本完成，但本项目优先修正文案源文本，并用 `text-autospace` 渐进增强，避免运行时改写 DOM 干扰动画。
- [adobe-fonts/source-han-sans](https://github.com/adobe-fonts/source-han-sans)：思源黑体作为可靠回退；不直接加载完整中文网络字体，避免增加首屏体积。

### 字体分工

- 中文标题与正文使用中文优先系统字体：苹方、Noto Sans CJK SC、思源黑体、微软雅黑 UI、微软雅黑、冬青黑体简体等。
- 英文项目名、年份和技术标签单独使用 Inter。
- 编号、参数和短标签使用 JetBrains Mono。
- 不让 Inter 作为中文容器的首选字体，避免逐字回退造成中英文基线和标点宽度不稳定。

### 字号与字距

| 层级 | 字号 | 行高 | 字距 |
| --- | --- | --- | --- |
| 首页姓名 | `clamp(4.5rem, 14vw, 13.5rem)` | `0.9` | `-0.045em` |
| 中文章节标题 | `clamp(2.75rem, 5.8vw, 6.25rem)` | `1.02` | `-0.035em` |
| 中文项目标题 | `clamp(3.25rem, 7vw, 7.5rem)` | `0.94` | `-0.045em` |
| 角色标题 | `clamp(1.4rem, 3.6vw, 3.6rem)` | `1.1` | `0.04em` |
| 正文 | `clamp(1rem, 1.1vw, 1.125rem)` | `1.75` | `0` |
| 导航与操作 | `0.75rem–0.8rem` | `1.5` | 中文 `0.04em` |
| 英文与编号标签 | `0.65rem–0.72rem` | `1.5` | `0.08em–0.12em` |

中文正文限制在约 `30–36em`，长篇阅读页最多 `48em`。标题使用 `text-wrap: balance`，正文使用 `text-wrap: pretty`；中文容器启用 `line-break: strict`、`word-break: normal` 和 `overflow-wrap: break-word`。

## 新首页构图

### 首屏

首屏继续使用纯色背景，不放游戏图片或视频。姓名拆成可独立进入的三个汉字，但屏幕阅读器仍只读取一次“朱翊嘉”。角色、简介、年份和滚动提示分布在不同网格位置，避免所有内容堆在左下角。首屏只承担身份建立，不提前展示项目封面。

### 精选游戏

两个项目改为两段不同构图的滚动叙事。第一项以大幅横向封面为主，标题和信息从右侧压入；第二项反向排布并改变媒体比例。编号作为背景层，年份与职责固定在信息轨道。封面链接仍直接打开原项目网页。

媒体进入视口时先解除遮罩，再产生很小的垂直速度差；悬停只做轻微缩放、标题位移和光标状态变化。动画只改变 `transform`、`opacity` 和 `clip-path`，并在降低动效模式下关闭。

### 关于与联系

关于区不再是一段巨型口号。采用短介绍、能力关键词、邮箱和 About 入口组成的不对称尾声，与首页的项目节奏形成收束。

## 连续交互

- 精细指针设备启用 Lenis 平滑滚动；触屏和降低动效模式使用原生滚动。
- 接回旧版自定义光标，并把项目媒体标记为“打开项目”状态。
- 路由页面使用同一组淡入、位移和遮罩缓动。
- 所有动画使用统一的 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 不依赖动画传递必要信息；键盘焦点和直接链接始终可用。

## 验收标准

- 中文姓名、角色、章节和项目标题的字面清楚，不出现汉字互相挤压。
- 中文正文在桌面保持舒适行长，移动端不出现过长单行或错误标点换行。
- 两个项目在构图上明显不同，但信息字段位置仍可预测。
- 滚动、媒体揭示、光标和页面切换具有一致节奏。
- 首屏保持纯色；两个原项目网页与其资源目录不被修改。
